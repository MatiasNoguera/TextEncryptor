# ENCRIPTADOR DE TEXTO / TEXT ENCRYPTOR

Encriptador de texto. Cambia las vocales por las palabras: a--->ai/ e--->enter/ i--->imes/ o--->ober/
u--->ufat

Text encrypter. Change the vowels for the words: a--->ai/ e--->enter/ i--->imes/ o--->ober/
u--->ufat
